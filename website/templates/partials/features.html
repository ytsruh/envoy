Features

Everything you need to manage environment variables.

Projects

Organize your variables into projects. Link directories to a project for automatic context.

Environments

Create dev, staging, production environments. Keep configs separate — misspelled names fail closed, never create strays.

Variables

Set, get, list, and unset variables per environment. Script-friendly output for CI.

Push / Pull

Push .env files in seconds with vars push. Pull them back down when deploying or onboarding.

Team Sharing

Invite teammates with one-time tokens. Control who can view or edit each project.

Secure Auth

JWT-based authentication. Your session, your access.
